# Genpass
Минималистичный и безопасный генератор паролей, оптимизированный для работы с Apple iCloud Keychain и Safari.
🚀 Возможности

    Криптографическая стойкость: Для генерации используется window.crypto.getRandomValues(), что делает пароли устойчивыми к подбору в отличие от стандартного Math.random().

    Интеграция с Keychain: Специальный механизм имитации отправки формы позволяет браузерам (особенно Safari на iOS и macOS) предлагать автоматическое сохранение пароля в связку ключей.

    Дизайн в стиле Apple: Чистый интерфейс с поддержкой темной и светлой тем.

    Безопасность данных: Приложение не использует cookies или localStorage. Все данные живут только в оперативной памяти (RAM) и стираются при закрытии или перезагрузке страницы.

    Индикатор надежности: Визуальная шкала оценки сложности пароля на основе его длины и состава символов.
